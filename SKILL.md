# Roblox Ranter Voice Chat Skill

## Overview
This skill launches an interactive Streamlit chatbot application designed for comedic Roblox rants, tech commentary, and hardware discussions, powered by multi-model AI APIs and ElevenLabs voice synthesis.

## How to Run
1. Ensure Python and dependencies are installed.
2. Run the Streamlit application using the command:
   \`streamlit run app.py\`
3. Interact with the chat interface to generate text and synthesized voice responses.
